# Earth Rescue

A retro space shooter game developed with LÖVE (Love2D).

## Description

Defend Earth (or at least yourself) from incoming alien enemies and asteroids!
As you progress, the difficulty increases, enemies become smarter and start shooting back, and the asteroid field gets denser.

## Features

- **Retro Graphics:** Classic arcade style with pixel-art assets.
- **Dynamic Gameplay:**
  - Procedural starfield background.
  - Splitting asteroids mechanics.
  - Shooting mechanics for both player and enemies (from Level 3+).
- **Settings Menu:** View controls and settings.
- **High Score:** Survive as long as you can to get the highest score.

## Controls

- **Mouse Movement:** Move the ship.
- **Left Click:** Shoot laser.
- **Esc (in menus):** Quit game.

## Installation

1. Install [LÖVE](https://love2d.org/).
2. Run the game:
   - Drag the folder onto the `love` executable.
   - Or run `love .` in the terminal from the game directory.

## Customization

To use a custom font, place a `.ttf` file in `assets/` and update `main.lua` to load it.
